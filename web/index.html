What this is

A teaching and testing tool for surrogate modeling, response surface methods and Bayesian optimization. You tune a fictional PECVD deposition process (six factors) to get the most uniform film, with a limited budget of wafers. Behind it is the Hartmann 6D test function: a sharp global minimum and a broad, flat second basin that is easy to settle into.

A first session (10 minutes)

  1. Plan a design. Keep the lab settings, pick Maximin Latin hypercube with 12 runs, and press Plan this design. The planned runs show as rings on the plots.
  2. Measure. Each run costs one wafer from the budget. Measurements are noisy but repeatable: the same settings and seed give the same numbers.
  3. Explore. The model panel shows the Gaussian process's prediction on a slice through two factors. Move the sliders or click a plot to move the slice. Switch Show to Uncertainty to see where the model knows least. The profiler shows one factor at a time.
  4. Optimize. Under Suggest next runs, pick an acquisition (expected improvement is the usual start), press Suggest, look at where it wants to go, then Measure. Watch the convergence chart.
  5. Compare. The Compare strategies tab shows how random search, a quadratic response surface and Bayesian optimization do over many seeded replicates at the same budget.

For instructors

  • Instructor view (top right) shows the true surface, the optimum and the second minimum, and how far the best run is from the optimum. It works on the honor system: this page runs entirely in the browser, so nothing is hidden for real.
  • Blind scenario reorders and reverses the factors with a seed, so the published Hartmann optimum can't be looked up. Give a class the same settings and seed so everyone's measurements agree.
  • Export the runs as CSV to analyze them in JMP; a design made in JMP can be pasted in under Import.

Other ways in

The same engine runs as a Python package and a command-line tool (hartmann design, hartmann run, hartmann benchmark), and a JMP add-in is on the way. See the repository.

The function

f(x) = −Σi αi exp(−Σj Aij (xj − Pij)²) on [0, 1]⁶, with its global minimum −3.32237 (SFU library). In process units the response is thickness non-uniformity (%) = 6.0 + 1.5·f, so the best possible is about 1.02 %.
